🏢 Devlog – Kontorlandskapplanlegger

Bygget iterativt med GitHub Copilot · Sist oppdatert: 5. mai 2026

Iterasjon 2 Lukket

Sky-oppsett + Lovable-frontend + multi-celle SVG-ikoner

Hva ble bygget
  • Sky-arkitektur: Backend på Railway, frontend i Lovable – to separate GitHub-repoer som jobber sammen.
  • Multi-celle elementer: Hvert element tar sin rettmessige plass på canvaset. Møterom (8–16) = 6×4 celler, kjøkken = 4×2, pult = 2×1. Støtte for manuell resize via toolbar.
  • Top-down SVG-ikoner: Alle 13 elementtyper har håndtegnede SVG-illustrasjoner sett ovenfra – pult med monitor og tastatur, møterom med bord og stoler rundt, kjøkken med benk/vask/kaffemaskin, toalett med skåler og servant.
  • Lovable-generert frontend: TypeScript + Tailwind + shadcn/ui, generert fra naturtro prompt. Peker automatisk mot Railway-API.
  • SSH-autentisering: Ed25519-nøkkel satt opp for GitHub-push uten token.
Arkitektur
Lovable (frontend) → https://[prosjekt].lovable.app ↓ API-kall Railway (backend) → https://kontorplanlegger-production.up.railway.app ↓ data JSON-filer → data/floorplans.json, bookings.json, config.json
Hva fungerte bra
Lovable genererte korrekt API-integrasjon på første forsøk Railway deployment rett fra GitHub-push SVG-ikoner gir tydelig visuell feedback om elementtype Multi-celle logikk med kollisjonsdeteksjon fungerer solid
Lærdommer
Lovable lager eget repo – ikke lag det på GitHub manuelt på forhånd Railway krever explicit GitHub App-tilgang første gang JSON-fillagring nullstilles ved Railway-redeploy – OK for demo Rolldown ARM64: rm -rf node_modules && npm install løser build-feil
Neste steg (Iterasjon 3)

Iterasjon 1 Lukket

MVP – Lokal planlegger med grid-canvas og elementpalette

Hva ble bygget
  • Prosjektoppsett: React + Vite + Express, JSON-fillagring, port 3001.
  • LocationSelector: Kaskaderende nedtrekkslister – Bygg → Etasje → Sone med sone-badge (stille/fokus/aktiv/sosial).
  • FloorPlanEditor: CSS-grid canvas (48px celler), klikk og dra for å male elementer, høyreklikk for å slette.
  • ItemPalette: 13 elementtyper i tre kategorier – Arbeidsplasser, Møterom, Dekor/infrastruktur.
  • Lagre/laste: PUT/GET mot Express-backend, JSON-persistens.
  • Admin/Booking-modus: Toggle-pill i header mellom redigeringsmodus og bookingvisning.
Hva fungerte bra
Grid-canvas med klikk og dra er intuitivt Kaskaderende dropdowns filtrerer korrekt Express + JSON gir rask og enkel persistens
Lærdommer
Express 5 path-to-regexp: bruk /{*path} ikke * for wildcard 1×1 celle-modell er for begrenset – møterom trenger egne størrelser
