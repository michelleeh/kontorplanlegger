## Iteration 5 — Enterprise-quality top-down SVG icons

Replace all emoji icons with professional inline SVG icons drawn from a top-down (plan view) perspective, as used in enterprise office planning tools like Archibus or Officespace.

### Style guidelines
- Clean line art, minimal fills, consistent 2px stroke
- Colors should match the existing element color scheme (blues for desks, greens for meeting rooms, etc.)
- All icons must look good at small sizes (the canvas cell is 60px wide)
- Top-down / bird's-eye view — not isometric, not perspective

### Icons to create (one per element type)

**Workspaces (top-down plan view):**
- `pult-skjerm`: Rectangular desk with a monitor outline (thin rectangle) and small keyboard bar at front edge
- `pult-laptop`: Rectangular desk with a small open laptop outline (thin trapezoid)
- `stapult`: Taller rectangular desk outline (slightly narrower, no monitor)
- `lounge`: Soft curved sofa shape (arc or rounded rectangle) with a small round table

**Meeting rooms:**
- `mote-lite`: Rectangular table with 4 small chair rectangles around it
- `mote-medium`: Oval/rectangular table with 6-8 chair rectangles around it
- `mote-stort`: Large rectangular table with 10+ chairs around it
- `telefonbod`: Small square with a phone handset outline inside

**Decor / infrastructure:**
- `vegg`: Solid filled rectangle (represents a wall segment)
- `plante`: Circle with simple leaf/petal shapes inside
- `kjokken`: Counter L-shape or rectangle with a sink circle and a small coffee machine rectangle
- `printer`: Rectangular box outline with a small paper sheet coming out the top
- `toalett`: Two toilet bowl outlines side by side (or one centered), with a small sink rectangle

### Implementation

Create a new component `src/components/ElementIcon.tsx` that exports:
```tsx
export function ElementIcon({ typeId, width, height }: { typeId: string; width: number; height: number }) {
  // Returns an inline SVG for each typeId, scaled to width/height
}
```

Update `FloorPlanCanvas.tsx` to render `<ElementIcon>` instead of `<span>{t.icon}</span>`.

Keep the `icon` field in `elements.ts` as a fallback (do not remove it).

All UI text remains in Norwegian.
