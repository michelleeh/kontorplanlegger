## Iteration 6 — Instant booking with real-time canvas status

### 1. Migrate the bookings table

Create a new Supabase migration that replaces the current `booking_date` + `time_slot` columns with `start_time` and `end_time` (both `timestamptz`). The new schema:

```sql
ALTER TABLE bookings
  DROP COLUMN booking_date,
  DROP COLUMN time_slot,
  ADD COLUMN start_time timestamptz NOT NULL DEFAULT now(),
  ADD COLUMN end_time timestamptz NOT NULL DEFAULT now();
```

Update `src/integrations/supabase/types.ts` to reflect the new schema.

### 2. Instant booking dialog

When a user clicks a bookable element in booking mode, show a dialog with:

- **Name field**: text input ("Ditt navn")
- **Duration selector**: radio buttons or segmented control with these options:
  - 30 minutter
  - 1 time
  - 1,5 timer
  - 2 timer
  - 3 timer
  - Resten av dagen (until 17:00 today)
- **Book-knapp**: sets `start_time = now()`, `end_time = now() + chosen duration`
- Do not allow booking if the element already has an active booking (`start_time <= now <= end_time`)
- Show a clear error/warning if the element is currently occupied

### 3. Canvas status indicators

Query all bookings for the current zone where `end_time > now()`. For each element on canvas:

- 🟢 **Ledig**: no active booking — default appearance
- 🔴 **Opptatt nå**: `start_time <= now() <= end_time` — show red overlay + tooltip: "Booket av [navn] — til kl. HH:MM"

Elements are automatically considered free once `end_time` has passed (no background job needed — just re-query on load and after each booking).

### 4. Keep existing features intact
- Admin/edit mode is unaffected
- Floor plan save/load is unaffected
- Location selector is unaffected

All UI text in Norwegian.
